# 27 · 多单工作台增强与次级回报口径（4.1）

> 适用：74 单（或任意 N 单）横向工作台、分银行页、单项目报告中的次级档收益展示。
> 本文件是 2026-11-02 实操修正的固化，防止“次级现金流混入别单”“回报倍数用错分母/分子”再犯。

## 一、次级档回报倍数的唯一算法

```
回报倍数 = 次级档累计现金分配（含本金 + 固定资金成本 + 超额收益）
          ÷ 次级档投资者实际认购金额（发行面值 × 发行价格 / 100）

次级 XIRR = 同一组现金流：期初 -实际认购金额，各分配日为正向现金流
```

**不得使用**：
- 受托报告里的「资产池预计回收金额」充当次级固定成本；
- `sub_income_paid` 未经逐期/清算对账直接与面值相加；
- 以发行面值代替投资者实际认购金额（发行价 >100 时会系统性高估倍数）。

**农盈利信远诚2023年第一期实例**：
- 原倍数 1.929x：`sub_income_paid = 60,381,768.54 = 2 × 30,190,884.27`；
- 30,190,884.27 是受托报告「2024-03-31 资产池预计回收金额」，不是次级固资；
- 实际分档兑付表：次级本金 6,500 万 + 固定资金成本 1,009.70 万 + 收益 55.17 万
  = 7,564.88 万；÷ 6,500 万 = **1.164x**；
- 次级 XIRR 12.62% 用实际现金流，原本正确，不受影响。

### 对账顺序
1. 先看逐期「分档兑付表」的 `sub_principal + sub_fixed_cost + sub_income`；
2. 若清算报告还有一次性分派，且逐期合计小于清算归属，才在清算日补差额；
3. 若逐期合计大于清算归属，记录 `sub_reconcile_gap`，**不得倒挂或重复计入**；
4. 回报倍数与 XIRR 必须使用同一组现金流；
5. 存续且次级未分配完：倍数/ XIRR 标「已实现/—」，不得写成最终回报。

## 二、发行日、发行价与信托设立日

- **投资者认购现金流日 = 发行日**（发行结果公告），不是信托财产交付日/信托设立日；
- 优先档发行价一般为 100；次级档发行价常见 100–117 元/百元面值；
- 报告须单列「发行日/投资者缴款日」与「信托设立日」，不得混写；
- 只有 4 个存续建鑫单已从发行结果公告补到可靠发行价；其余项目无发行价字段时按面值 100 计，并在口径注中说明。

## 三、禁止跨项目现金流兜底

单项目构建器不得内置别单现金流兜底（原 `_FB_SEN` / `_FB_SUB` 为惠元第三期）。
正确做法：
- 缺 `flows` 时用本单 `payload.periods` 重建；
- 次级档只有 1 笔认购流出也保留，不得因 <2 个点回落；
- 构建期断言：现金流日期必须属于本单（发行日或本单支付日），否则中止；
- 出报告后跑 `scripts/single/check_cashflow_contamination.py`：
  ```
  python scripts/single/check_cashflow_contamination.py \
    --report <report.html> --payload <payload.json>
  ```
  发现非本单日期即 EXIT=1，不得交付。

## 四、工作台（第一大部分）展示规范

### 项目卡（分银行页 `.pcard`）
固定 8 项：
`回收率 / 达成率 / 处置费率 / 次级占比 / 证券化率 / 优先XIRR / 次级倍数 / 次级XIRR`

- 证券化率 = 发行规模 ÷ 入池本息费；
- 次级 XIRR 与次级倍数并列，不得只给倍数；
- 存续项目次级 XIRR 标「已实现」；无分配时显示「—」。

### 分银行品种切片
每家银行页在 KPI 与项目卡之间增加一个「品种切片」：
- 按发行规模绘制堆叠条，颜色区分贷款品种（信用卡/个人经营/个人消费/住房抵押）；
- 图例列出每个品种：单数、发行规模、回收率中位、证券化率中位；
- 单品种银行也保留切片，显示为单段，保持五家页面结构一致。

### 次级 XIRR 全量入口
- 首页 KPI：次级回报倍数中位 + 次级XIRR中位；
- 计分卡：用「次级XIRR」替换「存续月数」，避免第一屏只有倍数；
- s3：Top/Bottom 双值（倍数 + XIRR）+ 各行次级中位表；
- 明细表：新增「次级XIRR」列，可排序/导出；
- 多单对比抽屉：增加「次级XIRR」「证券化率」列；
- 查看器顶部元信息：优先XIRR、次级倍数、次级XIRR、证券化率。

> 次级 XIRR 跨单不可直接横比（存续期差异大）：中位数只用已清算样本，
> 表头/说明标注；存续 4 单不纳入中位。

## 六、发行时间排序与品种/年份切片（4.1 追加）

- **项目顺序**：明细表全局按发行日升序（不再先按银行分组）；分银行项目卡、第一屏筛选结果
  同样按发行日升序。
- **切片位置**：第一屏（各行对比）与每家银行页各放一条「品种 × 发行年份」chip 条。
  品种：全部 / 信用卡 / 个人经营 / 个人消费 / 住房抵押；年份：全部 / 2021 / 2022 / 2023 / 2024。
- **联动范围**：
  - 第一屏：KPI（项目数/发行规模/累计回收/达成率/次级倍数/次级XIRR）、筛选摘要、项目带；
  - 分银行页：该行 KPI、项目卡数量与内容；
  - 明细表：与原有银行按钮/搜索条件叠加；
  - 顶部计数改为「匹配 N 单」，点「全部」复位。
- **实现要点**：
  - 服务端输出 `SLICE_ROWS`（项目名/银行/品种/年份/发行日/回收/证券化/倍数/次级XIRR/规模/状态）；
  - 第一屏/银行页共用 `.filterbar`，点击由 enhance 层统一 `applySlice()`；
  - 项目卡、表格行带 `data-variety` / `data-year`；
  - 静态 SVG 对比图不重绘，仍为全样本口径；筛选结果以“筛选摘要 + 项目带/卡片/明细”为准。
- **明细表银行按钮**：必须由 `BANKS` 动态生成，不能硬编码四家；当前 5 家计数
  中信 15 / 招商 18 / 建设 17 / 兴业 10 / 农行 14。

## 八、单项目报告四类修复（4.1 追加）

### 1) 预计回收曲线不能把“未披露”画成 0
- 若 `forecast_flow` 为空/合计为 0：**不画预计曲线**，图例只留实际；
  文字改为“中债仅披露预测总额 X 亿元、未披露逐期现金流，故预计侧不画曲线”，
  并列出预测总额与预测回收率；全周期达成率仍按累计回收 ÷ 预测总额。
- 禁止再出现“同口径 N 期累计：实际 X 亿元 vs 中债预测 0.00 亿元”。

### 2) ⑤ 实际收益与期限加关键日期时间轴
在 ⑤ 卡片下方加 6 个节点：
`发行日 → 首个支付日 → 优先档本金清偿 → 法定到期 → 信托终止/清算 → 末次报告期`。
- 优先档本金清偿优先取 `_Z_SEN`（逐期本金清零日），不先用 meta 的 settle 日期；
- 缺失节点显示「—」，样式置灰；
- 存续项目“信托终止/清算”显示「—」。

### 3) 处置费率必须讲清“已报销”
- 定义：**本项目目前报销的处置费用 ÷ 累计回收**；
- 不必然等于实际全部处置费用；各行报销尺度/可报销科目不同；
- 报告 ④/费用卡、工作台 s2、页脚统一口径注均须写明。

### 4) 瀑布字号与分档累计本金
- 瀑布图字号整体 +1（仅普通报告；`LEGACY_TEXT` 旧交付件保持原字号，G1 不变）。
- 分档本金清零期：按“发行规模 − 逐期本金累计”判断，不能直接读
  `sen/sub_balance_after`（部分单整列为 0，会误报第 1 期清零）。
- 分档累计本金走势同样按逐期本金累计倒推余额；与「存续期分配明细矩阵」勾稽：
  优先/次级清零期必须与矩阵本金列累计到发行规模的那一期一致。
- 实测农盈利信远新2022四：优先第 4 期（2023-10-26）、次级第 6 期（2024-04-26），
  原报告误写“第 1 期清零”。

> 以上 2)–4) 在 `LEGACY_TEXT` 下关闭/保留旧文案，因此惠元第三期 G1 仍为
> `deeef1e06070013a… / 205,040 B`，不需要 rebless。
