# 05 · 多 agent 协作与稽核

## 一、角色

| 角色 | 职责 | 禁止 |
|---|---|---|
| **Lead（我）** | 数据契约、组装器、验证器、**终稽核**、A–F 方案文档 | **不写业务模块**（避免既当运动员又当裁判） |
| **模块 agent** | 各自独占文件，实现 + 自检 + 回报 | 不碰别人的文件 |
| **稽核 agent** | 独立复核关键数字、发现 Lead 的错误 | 不改实现 |

## 二、Write scope 划分（示例，本项目实际）

| 模块 | 归属 |
|---|---|
| `00_ctx.py` / `build_v2.py` / `verify_v2.py` | **Lead 独占** |
| `10_overview.py` | a2-overview |
| `20_profile.py` + `70_wording.py` | a2-profile |
| `30_compare.py` | agent-compare |
| `40_audit.py` | agent-audit |
| `50_charts.py` + `60_assets.py` | agent-charts |

**一个文件只能有一个 owner**。若必须改别人的文件（如修 bug），先跟 Lead 说。

## 三、派工消息模板（必须写全）

```
【版本 · 任务名】只改 `<文件路径>`。

## 背景
用户原话/此前实测证据（带数字）

## 现状
（实测的 DOM/数据/截图证据，不要凭印象）

## 要求
1. ...
2. ...

## 数据（已核实，直接可用）
字段 / 可得率 / 结构示例

## 约束
幂等；IIFE；node --check；EXIT=0；不跑 build_v2.py；不动其他模块
必须保留：<已验收的成果清单>

## 自检（必须逐条打印）
1. ...
2. ...

## 回报
改了什么 + 自检数值 + EXIT
```

## 四、Lead 的稽核职责（**不能省**）

1. **独立复核关键数字**：不采信 agent 自检，自己用 Python 跑一遍源数据
   - 例：agent 说「残差 max 4.44%」→ Lead 自己算 `WF.residual/rec` 确认
2. **核实 agent 的「已完成」声明**：grep 产物、跑断言
3. **接受 agent 的反驳**：agent 若指出 Lead 的指令有事实错误（本项目发生过 3 次），**先核实再采纳**
   - 例：agent-audit 指出「那句在 S6 不在 S7」「S1 写『明细未单列』会与 S10 的 20/28 打架」→ 均正确，采纳
4. **断言归属**：Lead 写的断言若总是 FAIL，**先怀疑断言本身**（本项目 22 次断言失败中约 15 次是断言错，不是实现错）

## 五、并行 vs 串行

- **可并行**：不同文件的模块改造、方案文档写作、稽核扫描
- **必须串行**：同文件多人改、组装→验证（验证依赖组装）
- 一次消息里 **同时发多个 spawn/send_message**，不要一个个等

## 六、agent 交付后的标准动作

1. `build_v2.py` 组装
2. `verify_v2.py` 全量断言
3. **对 FAIL 逐条定性**：是实现问题还是断言问题？
   - 实现问题 → 给 agent 精准返工指令（带实测证据）
   - 断言问题 → 自己修断言（**不要为了通过而降低标准**；要改成更准确的判据）
4. 出预览图核对视觉效果
5. 写 README + 留痕

## 七、给 agent 返工的正确姿势

**不要只说「还是不对」**。要给：
- 实测证据（截图 / DOM 输出 / 数值）
- 根因判断（若已定位）
- 明确的验收标准（可量化）
- 保留清单（防止修 A 破 B）

例：
> ⚠️ P0 修复不彻底：p0 圆环中心现显示「万元」两个字（**数字丢了**），图例「19.56% · 2.33 万元」——但 19.56% × 11.92 亿 = **2.33 亿元**。你只改了单位词没改数值量级。要求：按 `prof.poolTotal` 重算，中心必须有数字。

## 八、回归防护

每轮加的断言**永不删除**（除非该需求被明确作废）。这样：
- 修 A 破 B 会立刻暴露
- 已知缺陷不会静默回归（例：担保方式异常备注曾在 v8.3 丢失，加了断言后再没丢过）

## 九、成本控制

- 一个模块一个 agent，不要为小改动开新 agent（复用已有 teammate）
- 大改造才多 agent 并行；小修 Lead 直接做
- 每个 agent 一轮交付，避免反复往返
