# 03 · V9 架构与交互

## 1. 两层结构

```text
基础壳 HTML
  ├─ 顶栏 / 筛选 / 视图骨架 / META / REPORTS / SLICE_ROWS
  ├─ V3_STYLE  <style id="v3-theme">
  ├─ V3_LIB    <script id="v3-echarts">
  ├─ V3_DATA   const V3_FULL = [...]
  └─ V3_APP    <script id="v3-app">
```

基础壳负责“有哪些项目、报告正文、原有视图”；
V3 层负责“切片状态、ECharts 图、HTML 现金流板、动态结论、导出/夜盘/打印”。

**唯一构建入口：** `scripts/inject_v3.py`。它按 `<!--V3_STYLE_START-->…<!--V3_APP_END-->` 幂等替换。
**禁止**直接改 V9 HTML 当源码；改完下次重建就丢。

## 2. 基础壳里的关键数据

| 变量 | 作用 | 当前规模 |
|---|---|---|
| `META` | 项目元信息（bank/variety/issue_date/recovery/…） | 74 |
| `REPORTS` | 项目名 → {b: 报告 HTML}；查看器 + 现金流/回购 | 74 |
| `SLICE_ROWS` | 首屏项目带/明细行 | 74 |
| `V3_FULL` | 图表所需全字段行 | 74 |

合并逻辑：`init()` 按 `proj` 去空格把 `V3_FULL` 字段并到 `SLICE_ROWS`；
再从 `REPORTS[r.n].b` 解析 `是否回购` 和 `data-label/data-cum` 现金流。

**只替换 V3_FULL 不替换 REPORTS** → 图表变、查看器/现金流仍旧，属于假成功。

## 3. 切片状态

```js
window.__slice = {
  varieties: [], years: [], tenor: [], sec: [], ach: [], state: [], buyback: []
}
```

- 普通点击 = 单选（该维度只保留这一项）；
- `Ctrl/⌘` 点击 = 多选/取消；
- 再次点同项取消；“全部”清空该维度；
- 银行页 `vslice` 同样；
- URL 查询参数：`sv/sy/st/ss/sa/sstate/sbb`；
- 所有图表从 `filteredRows()` 重建；KPI/摘要/洞察/项目带/明细表同步。

**不要在每个图里各写一套 if 筛选。** 统一走 `applyMultiSlice / filteredRows / refreshAll`。

## 5. 现金流 HTML 板

```text
#v3-cashflow-card
  .v3-chart-tools
  .cf-sum（4 个指标：可分配现金/优先档/次级档/费用）
  .cf-legend
  .cf-head
  .cf-body
    .cf-group（银行 + 单数 + 金额）
    .cf-row（button，data-bank/data-variety）
      .cf-name
      .cf-track > .cf-seg.p/.s/.f/.o
      .cf-val
```

点击 `.cf-row` → `setMultiSlice('variety', …, true)` + `showBank(bank)`。
每个行内百分比按**该行 total** 归一；顶部指标/图例按全样本归一。
颜色：优先 `#2F4570`、次级 `#B08A57`、费用 `#B42318`、其他 `#B9AFA2`。
卡片与上方网格间距 14px；禁止贴住。

## 6. 双列与卡片

6 组 `.v3-pair`：

1. 矩阵 + 计分卡（概览）
2. 资产池气泡 + 策略气泡（s2）
3. 票面 dumbbell + 优先×次级（s3）
4. 预测 + 分布（s4）
5. 资产质量×银行 + ×品种（s5）
6. 发行 + 年度表（s7）

桌面 `grid-template-columns: repeat(2,minmax(0,1fr)); gap:14px`；≤900px 单列。
卡片间距统一 14px；不要只在某一张卡加 margin。

## 7. 报告查看器

- 点气泡 / 项目卡 / 明细行 → `#viewer` 打开报告；
- 报告 iframe 注入浅色/红色主题，隐藏重复顶栏；
- 返回不丢切片；
- 报告正文来自 `REPORTS`；缺报告时不能空成功，要有空态。

## 8. 导出 / 打印 / 夜盘

- 切片 CSV：当前 `filteredRows`；
- PNG：ECharts 图（13 张；HTML 现金流板不在 canvas 内，打印/PDF 有）；
- PDF/打印：两栏、隐藏壳层、卡片避免断页、切片报告头；
- 夜盘：深色壳层 + 暖纸图表，localStorage 记忆；银行色/红绿语义不反转；
- URL 分享：切片写 query。

## 9. 改代码的边界

| 想改 | 改哪里 |
|---|---|
| 图数据/轴/图例 | `assets/source/v3.js` 对应 build 函数 |
| 卡片/双列/间距 | `assets/source/v3-extra.css` / v3.css |
| 注入顺序/数据块 | `scripts/inject_v3.py`（极少改） |
| 新数据集 | 行 + 基础壳 META/REPORTS/SLICE_ROWS + 注入 |
| 单项目数值 | 第一技能，不在本技能 |

改完必须重建 + G0/G1/G2/G3；不要手改 dist 后交付。
