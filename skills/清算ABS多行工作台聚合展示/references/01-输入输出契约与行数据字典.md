# 01 · 输入输出契约与行数据字典

## 1. 输入：单项目目录

```text
<项目>/
├── 02_提取数据/metrics.json       必需；39 个已算指标
├── 02_提取数据/payload.json       必需；meta/pool/tranche/periods/...
├── 03_报告产出/*_不良ABS穿透分析_v*.html  必需；查看器 + 现金流/回购
├── 03_报告产出/_assert_single.json        建议；FAIL/SKIP
└── 01_下载文档/                    可选；工作台不读
```

`aggregate_rows.py` 扫描 `<项目根>/*/02_提取数据/metrics.json`。
缺 metrics/payload：该目录不进聚合；缺报告：行可以进，但查看器/现金流为空，必须显式记录。

## 2. 输出：工作台

单文件 HTML（自带 ECharts + 数据 + 报告），离线可开。
内部四块：

| 块 | 内容 |
|---|---|
| 基础壳 | 顶栏、区块、`META`、`REPORTS`、`SLICE_ROWS` |
| `V3_STYLE` | `v3.css` + `v3-extra.css` + `v3-gold.css` |
| `V3_LIB` | `echarts.min.js` |
| `V3_DATA` | `const V3_FULL = [...74 rows...]` |
| `V3_APP` | `v3.js` |

注入器用 `<!--V3_*_START/END-->` 标记做幂等替换。

## 3. 行数据字段（canonical）

| 字段 | 必填 | 类型/单位 | 来源/公式 |
|---|---|---|---|
| `bank` | 是 | 5 家之一 | meta.originator_short |
| `proj` | 是 | 唯一键 | meta.display_name；去空格匹配 |
| `variety` | 是 | 4 类之一 | meta.variety + 正文复核 |
| `issue_date` | 是 | YYYY-MM-DD | 说明书/发行结果 |
| `legal` | 否 | date | 法定到期日 |
| `term` | 否 | date | 信托终止/清算完成 |
| `state` | 是 | settled/open | 清算文书 |
| `life` | 是 | 月 | 已清算：终止−发行；存续：报告期末−发行 |
| `issue` | 是 | 元 | 发行规模 |
| `pool` | 是 | 元 | 入池本息费 |
| `sec_rate` | 是 | 0–1 | issue/pool |
| `sub_pct` | 是 | 0–1 | sub_issue/issue |
| `coupon` | 是 | 0–1 | 优先档票面 |
| `recovery` | 是 | 0–1 | recovered/pool |
| `exp` | 是 | 0–1 | 预计回收率；可由 recovered/achieve/pool 验证 |
| `achieve` | 是 | ratio（可>1） | recovery/exp；1.013=101.3% |
| `dispose` | 是 | 0–1 | 已报销处置费/累计回收 |
| `servicer` | 是 | 0–1 | 服务报酬/累计回收 |
| `fee` | 是 | 0–1 | fee_total/recovered |
| `sen_xirr` | 是 | ratio | 现金流 XIRR |
| `sub_xirr` | 是（settled） | ratio | 已实现；open 可 null |
| `mult` | 是（settled） | x | Σ次级分配/次级实际认购；open 可 null |
| `n_loans`/`n_bor` | 否 | int | 说明书 |
| `avg_loan` | 否 | 元 | 说明书 |
| `wavg_od` | 否 | 月 | 说明书 |
| `sub_bal/doubt/loss` | 否 | % | 资产质量加权 |
| `sub_amt/doubt_amt/loss_amt` | 否 | 万元 | 资产质量余额 |
| `recovered` | 是 | 元 | 受托+清算 |
| `sen_issue`/`sub_issue` | 是 | 元 | 发行结果 |
| `line` | 是 | 短名 | 品种映射 |
| `year` | 是 | string | issue_date[:4] |
| `fails`/`skips` | 是 | array | 单项目断言；FAIL 非空不得进 |

## 4. 缺失处理

- 未披露：`null`，不补 0、不补均值。
- 存续单：`sub_xirr`/`mult` 可为 null；工作台显示“—”。
- 报告缺失：现金流/回购为空；不得跨项目兜底。
- 单项目 FAIL：`fails` 非空；行校验/交付门禁失败。
- 不允许 NaN/Infinity；JSON 序列化前 `math.isfinite`。

## 5. 唯一键与排序

- 唯一键：`proj` 去所有空白；
- 排序：`issue_date` 升序，再按 `proj` 稳定排序；
- 期次不能按字符串：10 期会排在 2 期前；一律用发行日/期末日。

## 6. 行文件格式

```json
[
  {
    "bank": "中信银行",
    "proj": "惠元2021年第一期",
    "variety": "信用卡不良",
    "issue_date": "2021-06-30",
    "state": "settled",
    "life": 24,
    "...": "..."
  }
]
```

输出：`ensure_ascii=False, indent=2, sort_keys=True, newline="\n"`。
SHA256 对**字节**计算，不对对象计算；换行/顺序变化都会改变哈希。

## 7. 报告 HTML 契约

查看器/现金流解析依赖：

- 报告内“存续期分配明细矩阵”行：`<tr data-label="..." data-cum="...">`；
- 行内两个 `td.l`：第一列科目、第二列分类（“费用”等）；
- 正文包含 `是否回购` 字段；
- 报告可独立打开（单文件、无外链）。

缺 `data-label/data-cum` → 现金流 0；缺“是否回购” → 回购空白。
