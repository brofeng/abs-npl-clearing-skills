## 6. 如何更新本规格

```bash
# 1) 改完代码，重新构建
<python> scripts/v2/build_v2.py

# 2) 重新生成基线指纹
<python> scripts/probe_report.py --html <新报告> --mode extract --out assets/golden/report_spec.json

# 3) 重新生成本文档
<python> scripts/gen_layout_doc.py --spec assets/golden/report_spec.json \
        --out references/12-版式像素规格.md

# 4) 重新生成黄金截图
<python> scripts/visual_regression.py --html <新报告> --mode snapshot --out assets/golden/screens
```

> ⚠ **基线不是「自动接受」**：更新基线等于宣布「新版本才是对的」。
> 更新必须在 README 里写清「为什么变」，否则视为回归。
