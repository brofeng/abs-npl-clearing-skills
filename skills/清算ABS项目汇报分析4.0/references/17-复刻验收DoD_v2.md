# 17 · 复刻验收 DoD（技能 2.0 · 单项目八节报告）

> **一句话**：本技能的单项目报告是**确定性构建**——同输入、同环境，产物 SHA256 完全一致。
> 「做不出一样的东西」只有四种原因：没用自带脚本 / 漏跑模块 / 自己重写 / 没验证。

---

## 一、★★★ 五条铁律（违反必失败）

### 铁律 1 · 必须跑自带脚本，不要重写

```bash
python scripts/single/build_single.py --out <输出目录>     # 唯一构建入口
python scripts/single/repro_gate.py --html <产物>          # 一键门禁
```

禁止行为：
- 读一遍 `build_single.py` 然后自己写一个「思路一样」的生成器 → 必然漂移
- 手改 `assets/single/v11_base.css` / `v11_enh.css`（26 万字符里藏着 0.5px 间距、
  `scope_css` 三个坑、标签配平、重绘时机等未文档化细节）
- 用 pandas / jinja / 其他模板引擎「重新实现一遍排版」

### 铁律 2 · 窗口尺寸必须 1600×1400

```python
WINDOW_W, WINDOW_H = 1600, 1400   # 写在 build_single.py / probe_single.py 里，不得改
```
响应式断点（1180 / 900 / 767 / 560）会改栅格列数、卡片高度、字号。**换尺寸就不是那张图**。

### 铁律 3 · 交付前 `repro_gate.py` 必须 EXIT=0

不跑 = 不知道对不对。跳过验证视为未完成。

### 铁律 4 · 不要为了让门禁通过而改基线

基线（`assets/single/golden/`）是用户已验收的样子。改基线 = 宣布新样子才对。
**只有用户明确要求改版**时才允许 `--rebless`，且必须在 `README.md` 写明原因。

### 铁律 5 · 不要手改输出换行

`build_single.py` 用 `open(..., "w", encoding="utf-8", newline="")` 写入，**不转换换行符**。
若改成默认 newline（Windows 会转 `\r\n`），文件会大 1,483 字节，G1 立刻失败。

## 五、失败定位表

| 现象 | 原因 | 处理 |
|---|---|---|
| G1 不等但大小相近（差 ~1,483 B） | 换行被转成 `\r\n` | 恢复 `newline=""` |
| G1 不等且大小明显不同 | 用了别处的 `payload.json` / 改过 CSS | 比对 `assets/single/INPUTS.sha256` |
| G1 不等，`build` 时报「输入校验失败」 | 有人改了输入数据 | 恢复原始 `assets/single/` 5 个文件 |
| G2 高度差 1–2px，其它全过 | 字体渲染差异（不同 Windows 版本） | 先统一系统字体（微软雅黑 UI 必须存在） |
| G2 高度差 >5px，文案也对不上 | 版式真的变了 | 看是哪个计数项变了，回查对应 sec 函数 |
| G2 文案差在第 N 行 | 文案被改（含一个标点） | 对照 `references/16` 与 `spec.json` 逐字恢复 |
| G2 字号分布多出某档 | 新增了字号 | 只用设计系统的 15 个档位，不自创新档 |
| G3 复算失败 | 数据源变了 | 检查 `metrics.json` / `payload.json` 是否被替换 |
| G3 禁用词失败 | 文案里混入内部术语 | 见 `references/16` 第十一节 |
| 产物能打开但侧栏切不动 | JS 被截断（标签未配平） | 不要手改 `JS` 常量 |

## 九、什么情况下允许改基线

只有这三种：

1. **用户明确要求改版**（如「把瀑布和分档本金合成一张卡」）
2. **数据回源修正**（发现披露文件读错，需同步 `payload.json` + `INPUTS.sha256`）
3. **设计系统升级**（改令牌，需同步 `v11_enh.css` + 重新采指纹）

流程：

```bash
# 1) 改代码 / 改数据（改数据要同步 INPUTS.sha256）
# 2) 重新构建
python scripts/single/build_single.py --out ./
# 3) 人工确认视觉无误（开 HTML 看，或看 shots_single.py 出的图）
python scripts/single/shots_single.py --html <产物> --out ./预览图
# 4) 重设基线
python scripts/single/repro_gate.py --html <产物> --rebless
# 5) 重新生成规格文档（否则 references/15 与基线脱节）
python scripts/single/gen_single_spec_doc.py
# 6) 在 README.md 写清「为什么变」
```

> ⚠ 第 5 步最容易漏。漏了会出现「门禁通过但文档写的还是旧高度」，下一个 agent 照文档做必然错。
