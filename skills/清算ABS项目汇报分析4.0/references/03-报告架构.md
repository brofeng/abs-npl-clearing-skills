## 二、模块契约

每个模块导出三个字符串：`CSS` / `HTML` / `JS`。

| | 约定 |
|---|---|
| `CSS` | **不写 `#view-xcompare` 前缀**（组装器 `scope_css` 会加）；不写注释（注释里的 `{}` 会破坏括号匹配） |
| `HTML` | **不含 `<section>` 外壳**；类名统一前缀（`xc-` / `a-` / `ov-` / `pf-`） |
| `JS` | 纯 IIFE 局部变量；不含 `<script>` 外壳；幂等 |

## 三、组装器 `build.py` 必做

1. **标签配平校验与自动修复**：模块 HTML 若 `</div>` 多于 `<div>`，会把宿主 `.main` 提前闭合 → 后续 section 掉到 `.app` 外、被挤到页面最底部（表现为「空白视图」）。
   ```python
   div_o = len(re.findall(r"<div\b", html)); div_c = len(re.findall(r"</div>", html))
   if div_c > div_o: html = re.sub(r"</div>\s*$", "", html, count=div_c-div_o)
   ```
2. **视图合并顺序**：`30_compare` → `#view-xcompare`，`40_audit` → `#view-appendix`，全局增强模块（`70_wording` 必须**最后**跑，文案改写优先级最高）
3. **滚动修复**：原报告 `document.querySelector('.main').scrollTo(0,0)` 是**静默无效**的（`.main{flex:1}` 不是滚动容器）→ 注入 `toTop()`：临时关掉 `scroll-behavior:smooth`、清各容器 scrollTop、`requestAnimationFrame` 恢复
4. **CSS scope**：`scope_css(css, root)` 三个坑
   - 注释含 `{}` → 先剥离注释
   - 选择器已含 root → 跳过，不重复前缀
   - `:root`/`html`/`body` → 映射为 root 本身

```python
__V2 = {

  "ORDER":  [key…],              # 视图顺序

  "WF":     {key: {...}},        # 瀑布（v6 重建：分档兑付表口径 + 处置费检测 + 残差）
  "DIST":   {key: {10类分布}},   # 分布数据（v8 注入）
}
```

### `WF` 瀑布结构（重要，别自己再算）
```js
{rec, disp, dbl, steps:[{label, value, kind:'in'|'out'|'sec'}], totalOut, residual, note}
```
- `kind:'sec'` 来自**分档兑付表**（`alloc2` 的 tier leaf），**不用 `alloc.cum`**（后者把「优先档本金」写成优先+次级总本金）
- `dbl=true`：检测到处置费用重复计入，已从 steps 剔除，`note` 说明
- 28 单验证：残差 <1% 的 21 单、≥5% 的 0 单、最大 4.44%

## 五、验证器 `verify.py` 架构

```python
# 1) 静态断言（读源文件）
chk("类别", "描述", 条件, 详情)

# 2) 渲染断言（关键）
probe = """
setTimeout(function(){
  var o={};
  ... 测量 ...
  document.title='VRESULT:'+JSON.stringify(o);   ← 用 title 回传，最可靠
}, 2600);
"""
html = 产出html.replace("<head>", "<head>"+errorHook).replace("</body>", f"<script>{probe}</script></body>")
subprocess.run([EDGE, "--headless=new", "--disable-gpu", "--no-sandbox",
                "--window-size=1600,1400",          ← 必须设！否则触发响应式降级
                "--virtual-time-budget=30000", "--dump-dom", url])
dom = stdout
res = json.loads(re.search(r"VRESULT:(\{.*?\})", title).group(1))
```

**渲染断言的七个必备技巧**（详见 `06-踩坑与断言方法论.md`）：
1. 必须 `--window-size`，否则窄视口触发响应式（6 列变 3 列、3 列变 1 列）
2. 非激活视图 `display:none` → `getBoundingClientRect()` 全 0 → **先 click 激活再量**
3. 图表转换/渲染是**视图激活时**触发的 → 没点进去过的视图还是原始态
4. `innerText` 会把 `opacity:0` 的未入场元素算进去 → 可见性判定用 TreeWalker + computedStyle
5. 客户端改写后，**源文件仍含原文** → 去术语/去旧措辞只能查渲染后
6. 类名不要猜 → 先跑一次探针 dump 真实 class
7. 测量时机：探针里若中途切了视图，之前量的都失效 → 按「激活 → 量 → 再激活下一个」串行

## 六、版本与留痕

- 交付物**每轮重命名**（v2…v11），不覆盖
- `_rebuild_log/summary_v2.json` 记录断言数 / PASS / FAIL
