## 一、设计主张（5 条，不是模仿是判断）

1. **材质分层取代描边**：`画布(冷灰蓝) → 纸面(白) → 次级面(paper-2/3)` 三层。**信息靠面层明度差分层，不靠边框**（财务表数字多、线多，越少线越清晰）
2. **双声部排版**：
   - **衬线**（Songti/SimSun/serif）**只用于「陈述」**：节标题、结论短句、口径批注
   - **数字**一律无衬线 + `font-variant-numeric: tabular-nums` + **右对齐** + **单位下沉为小字**
3. **语义色克制**：正常值一律墨色；`seal/amber/green` **只在真异常时出现**（超限/缺口/口径差/已更正），避免彩虹化
4. **小圆角 + 胶囊对比**：容器 `6/10/14`，只有标签/徽章用 `pill(999px)`
5. **阴影极轻**：只用于浮层（hover、折叠展开、抽屉）；常规卡片靠面差

## 三、落地要点（从 11 轮返工里总结）

| 要点 | 说明 |
|---|---|
| **不要靠边框分层** | 早期版本大量 `border:1px solid`，被批「土」→ 改材质三层后质感提升 |
| **数字必须 tabular-nums + 右对齐** | 否则列不对齐，一看就不专业 |
| **单位下沉为小字** | `11.92 亿`（亿是小字灰色），不是 `11.92亿` 通排 |
| **品种色 ≠ 风险色** | 品种色是分类标识（信用卡红/消费蓝/经营绿）；风险色只在真异常用。**要在页面里写明「品种色仅作分类标识，不代表风险等级」** |
| **卡片不要固定高** | 行内等高（高差 ≤4px），行高按内容自适应，上限 300–380px |
| **图表字号统一** | 标题 12px / 数据与图例 10–11.5px / 图注 9.5–10.5px；同图 ≤3 种 |
| **响应式** | ≥1180 桌面 12 列 / 768–1179 平板 6 列 / <768 手机 1 列；**禁止整页横向滚动** |
