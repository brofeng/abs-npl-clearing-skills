## 一、清算报告：**三种体例**，不是一种

这是最容易踩的一条。三家审计口径、章节结构、字段名全不一样，
**用一套解析器通吃必然错**。

| | 德勤版（中信惠元） | 毕马威版（建行建鑫） | 兴业信托版（兴业兴瑞） |
|---|---|---|---|
| 主表 | 清算资产负债表 + 业务及管理费 | 资产负债表 + 营业费用 + **专项报告附件** | **无资产负债表**，二三四五散文段落 |
| 记账基础 | 权责发生制 | 权责发生制 | **收付实现制** |
| 累计回收来源 | 清算报告「收回基础资产回收款」 | 同左 | 同左（已含回购价款） |
| 费用明细 | 业务及管理费 9 项 | 营业费用 + 附注 | 「三、信托税费支出情况」8 项散文 |
| 持有人权益 | **有**（可做两条恒等式） | **有** | **无** → 恒等式只能 SKIP |
| 清算净收益 | 有 | 有 | 利润及利润分配表「可供分配信托利润」 |
| 解析入口 | `parse_deloitte()` | `parse_new_style()` | `parse_xy_liq()` |

**体例分派判据（不要靠文件名、不要靠机构名）**：

```python
if "信托税费支出情况" in t and "证券本息兑付情况" in t:
    return parse_xy_liq(t, L)          # 兴业信托版：散文段落
if "清算资产负债表" in t and "业务及管理费" in t and "贷款服务报酬" in t:
    return parse_deloitte(t, L)        # 德勤版：报表 + 附注
# 其余 = 毕马威版 / 招行末次受托报告体例
```

### 1.1 招行的「清算报告」其实是一份末次受托机构报告

只有 16 页，结构就是受托报告模板（账户概况／证券概况／资产池表现／信用增级／重大事项）。
**没有清算资产负债表、没有持有人权益、没有清算净收益**，
所以中信那两条清算恒等式在招行**结构性无法验证** → 断言必须走 SKIP，不能判 FAIL。

> 判据：`residual_asset` 与 `holder_equity_end` 都取不到。
> payload 里写 `no_balance_sheet=True`，报告正文据此置灰并写明「本单无清算资产负债表」。

### 1.2 建行有两套：2021–2022 华润信托+德勤，2023 起金谷信托+毕马威

同一个品牌内部换过受托人和审计，**清算报告体例跟着换**。
不要以为「建鑫都是一个样子」。

## 二、次级档固定资金成本：**两种体例**，单期分不出来

「证券利息总支出」这一格含不含「次级档超额收益」，各家不一致：

| 体例 | 等式 | 固资算法 | 实测行 |
|---|---|---|---|
| **A**（超额并入利息） | int ＝ 优先息 ＋ 固资 ＋ 超额 | 固资 ＝ int − 优先息 − 超额 | 招行部分单、建行部分单 |
| **B**（超额单列） | int ＝ 优先息 ＋ 固资 | 固资 ＝ int − 优先息 | **兴业 10 单全部** |

### 为什么单期判不出来

2022 三期 p6：int 413 万、优先息 0、超额 211 万。
按 A 算固资 202 万，按 B 算固资 413 万，**两种都讲得通**，因为单期没有第三个约束。

### 唯一可靠的判据：用清算报告总额反推

```
Σ(int − 优先息) ＋ Σ超额 ≈ 清算归属次级收益   →  B
Σ(int − 优先息)          ≈ 清算归属次级收益   →  A
```

实测（兴业 10 单全部命中 B，误差 0.00）：

| 项目 | Σ(int−优先) | Σ超额 | 合计 | 清算归属 |
|---|---|---|---|---|
| 兴瑞2023七期 | 747,945.21 | 2,754,250.14 | 3,502,195.35 | 3,502,195.35 |
| 兴瑞2022三期 | 4,129,457.09 | 2,116,683.54 | 6,246,140.63 | 6,246,140.63 |
| 兴瑞2021一期 | 6,032,689.30 | 3,194,491.99 | 9,227,181.29 | 9,227,181.29 |

### 交叉验证技巧（强烈建议）

按 B 拆出来的固资，除以次级档发行额、按实际天数折年化，应等于**合同约定的资金成本率**：

```
兴瑞2023七期：747,945.21 ÷ 14,000,000 × 365 ÷ 195 天 = 10.00%
```

**整十、整百的百分数就是合同利率**，这是拆分正确的强证据。
若算出来是 7.3% / 12.8% 这种非整数，说明拆错了。

### 负残差怎么办

兴瑞2021二期：逐期合计 11,221,327.44 > 清算归属 11,201,690.26，差 −19,637.18（0.18%）。
成因是末期「证券利息总支出」混入了非证券项。

**正确做法**：记 `sub_reconcile_gap` 如实披露，**不挂清算日、不调整逐期**。
负残差计入现金流会导致重复计算（08 的 `_resid > 0.01` 判断即为此）。

## 三、期次排序：**必须用「本期期末日」**

文件名里带的是**下载日**，与报告所属收款期不一致。实测：

```
受托机构报告_兴瑞2021年第二期_20220429.pdf   ← 文件名 4-29
内容：「本期期初日 2021年8月10日／本期结息日 2021年12月26日」
      → 它是第 1 期（2021-12-31 期末）的报告，只是补下载于 2022-04-29
```

按文件名排会把它插到 2022-03 之后，逐期余额出现「91,170,000 → 225,000,000」反向跳升，
矩阵合计被算成 188%。

### 排序键优先级

```
本期期末日  >  本期结息日  >  本期支付日
```

**为什么优先期末日而不是支付日**：兴业是**月度报告 + 季度报告混合**，
同一支付日可能有两份报告（2021二期：TR02 期末 2021-11-30、TR04 期末 2021-12-31，
两者结息日都写 2021-12-26）。按支付日排会把顺序搞乱、还会误判成「重复期次」。

期末日在同一项目内**唯一且单调**，是最稳的期次键。

## 四、★ 年度受托机构报告：**混在期次里，会把回收和利息算两遍**

银行年报里附的「年度受托机构报告」，它的「本期」是**自信托设立日起至年末的累计**，
不是单期。当成独立期次收录，同一笔就计两次。

| 项目 | 被误收期次 | 该期付息 | 实际等于 |
|---|---|---|---|
| 兴瑞2021二期 | 2021-12-31 | 1,538,017.09 | p1 ＋ p2 之和（精确到分） |
| 兴瑞2021二期 | 2022-12-31 | 2,269,980.15 | p4〜p7 之和 |
| 兴瑞2022三期 | 2022-12-31 | 1,640,140.06 | p1 ＋ p2 之和 |
| 兴瑞2023四期 | 2023-12-31 | 677,374.18 | p1 ＋ p2 之和 |

### 判据（两条同时成立，不依赖文件头 OCR 文字，防错字）

1. 该期「本期支付日」**缺失**（年度报告没有支付日）；
2. 该期付息 ≈ **前面连续 k 期**付息之和（k≥1，容差 0.05 元）；
   付息为 0 时退用「本期兑付本金」做同一判据。

命中即整期剔除，理由写进 `payload.dropped_annual` 供报告脚注引用。

### ★★ 绝对不要用「等比例缩放」去配平

这是本项目最贵的一个教训。查不出年度期次时，曾用「按清算口径等比例缩放逐期利息」
把合计拉回正确值，缩放比 0.500 / 0.604 / 0.745 —— **合计对了，每一期都错了**。

这类失真比不配平更难发现：所有汇总断言都通过，只有逐期明细是错的。

> 正确顺序永远是：**先查期次是否重复，再谈配不平**。
> 期次干净了，逐期合计自然等于清算口径（实测差额 0.00），根本不需要缩放。
> 缩放逻辑保留作最后保险，但触发时必须在 payload 留痕（`fee_calibrated`）。

## 五、预计回收：**中信取中债、招行取主承销商**——方向相反

| 项目 | 中债 | 其他 | 说明书采用 |
|---|---|---|---|
| 中信 惠元2022四期 | 64,218.76 万 | 联合资信 70,359.91 万 | **中债** |
| 招商 和萃2021二期 | **31,639.62 万** | 主承 29,000.30 / 新世纪 28,829.29 | 主承销商 |

中信原文：「考虑历次项目估值可比，故本期项目选用了中债资信预测结果。」
招行原文：「与主承销商的预计回收情况吻合度较高，因此本期项目采用主承销商的预计回收总额。」

**但定源铁律不变：预计回收只认中债。**
招行若直接取说明书的 29,000.30，达成率分母错 2,639 万元（差 8.3%）。

> 教训：**不能按行照抄取数路径**，必须逐单看清楚说明书引用的是哪家机构的估值，
> 然后再按铁律换成中债值。

## 六、分布表列顺序：中信与招行**相反**

| | 第 3–4 列 | 第 5–6 列 |
|---|---|---|
| 中信惠元 | **预计回收 / 回收占比** | **资产笔数 / 笔数占比** |

## 八、累计回收：**早期受托报告会倒退**

招行第 2–7 期受托报告的「累计回收金额」只统计在册资产、不含已处置完毕部分
（实测第 2 期 7,753 万 < 首期 1.21 亿，明显倒退）。

**正确做法：一律用「本期回收金额」逐期累加。**
实测累加合计 278,127,994.00 与第 14 期报告累计完全相等，差额 0.00。

### 五级分类的表名陷阱（建行）

房贷 4 单原文写作「**贷款种类分布**」，表体才是次级/可疑/损失。
只认「五级分类」四字 → 全判「未披露」，还用「已核 p120–p127」自证。

> **凡「未披露」结论，必须能给出原文搜索命中数 = 0 的证据。**
> 置灰理由里写「已核 pXXX」这种话，后续没人再去核对，是最危险的自证。

## 十、每接一家新行，按这个顺序查

1. **品种**：逐期读说明书正文，不能按系列名推（和萃 2016 二期是小微、三期是对公）
2. **清算报告体例**：德勤 / 毕马威 / 信托版？有无资产负债表？
3. **次级固资体例**：A 还是 B？用清算总额反推，再用「折年化是否整十」交叉验证
4. **期次排序键**：期末日唯一吗？有没有年度报告混入？
5. **预计回收取源**：说明书引的是中债还是主承销商？
6. **分布表列序**：按表头定位，不写死
7. **账户层级**：子账户 / 分账户
8. **累计回收**：是「逐期累加」还是「直接取累计列」？
9. **单位**：预测表是元还是万元？
10. **术语**：固定资金成本 / 预期资金成本？五级分类 / 贷款种类分布？

查完这 10 项再动手，比写错了回头改快 5 倍。
