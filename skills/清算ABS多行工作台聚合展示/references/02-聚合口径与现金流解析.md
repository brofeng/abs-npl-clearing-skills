## 1. 单项目行口径

```text
sec_rate = issue / pool
sub_pct  = sub_issue / issue
recovery = recovered / pool
exp      = 预计回收率（中债口径；可由 recovered/achieve/pool 校验）
achieve  = recovery / exp        # 金额÷金额；可 >1
dispose  = 已报销处置费用 / 累计回收
servicer = 贷款服务报酬 / 累计回收
fee      = fee_total / recovered
mult     = Σ次级现金分配 / 次级实际认购金额
```

**不要用百分比反推金额。** 农行/建行多单存在四舍五入，`exp` 常为 4 位小数；
行校验对 `achieve` 用 2e-3 容差，其他比率 1e-6。

## 2. 次级倍数（最容易错）

正确：`Σ 次级档现金分配 ÷ 次级档实际认购金额`。
实际认购金额 = 次级发行规模 × 发行价 / 100（若发行价非 100）。

禁止：

- 用资产池预计回收金额当次级固资；
- 用 `sub_income_paid` 未对账直接加总；
- 存续单用 1.0 或预计值补；
- 把回购价款重复计入回收。

存续 4 单（建鑫 2021 四/七、2023 四/七）次级倍数可为 `—` 或低值；按已实现现金，不补。

## 3. 现金流去向解析

来源：单项目报告 ④“存续期分配明细矩阵”累计金额。

正则：

```js
/<tr data-label="([^"]*)" data-cum="([^"]*)"[^>]*>([\s\S]*?)<\/tr>/g
```

分类：

| 字段 | 判据 |
|---|---|
| `sen` | `data-label` 以“优先档”开头 |
| `sub` | `data-label` 以“次级档”开头 |
| `fee` | 行内第二列分类 == “费用” |
| `other` | 其余 |
| `total` | 四项之和 |

费用包含：税费、处置费、服务费、中介机构报酬等。
其他包含：发行费用、其他费用、转存下期（若报告矩阵列为其他）。
**占比按每个 银行×品种 行归一**，不是全样本归一。

现金流 74/74；缺矩阵不补。

## 6. 资产池表 vs 气泡

- s2 资产池表：**银行聚合**（单数、资产池、预计/实际回收率、处置费率、回收额、实际−预计）；
- s2 资产池气泡：**单项目点**（横轴池规模、纵轴预计回收率）；
- 不能把表的中位数当每个点；
- 也不能把气泡的点数当银行单数（同银行多期）。
