# 数据来源与合规声明

## 一、本仓库含什么

| 类别 | 是否包含 | 说明 |
|---|---|---|
| 分析脚本、门禁、模板 | 包含 | 全部为方法实现 |
| 口径台账、反模式清单、体例差异 | 包含 | 全部为方法沉淀 |
| 单项目报告产物（HTML） | 包含 | 对**公开披露信息**的加工结果 |
| 74 行聚合数据（canonical） | 包含 | 字段为证券代码、发行规模、回收率等技术指标 |
| 原始项目 PDF / 说明书原件 | **不包含** | 请自行从公开渠道获取 |
| 借款人信息、客户名单、联系方式 | **不包含** | — |
| 机构内部文件、未披露数据 | **不包含** | — |

## 二、数据从哪里来

所有数值均来自**银行间市场公开披露**的证券化文件：

- 受托机构报告（受托机构按监管要求定期披露）；
- 清算报告 / 结清报告（清算期项目终局披露）；
- 发行说明书、评级报告（发行时公开挂网）。

本仓库不含任何非公开渠道获取的材料。

## 三、口径差异的必然性

同一项目在「公开披露口径」与「机构内部台账口径」之间常见差异来源：

1. **费用归集方式**：已报销 / 未报销、含税 / 不含税；
2. **回收的时点归属**：按回收款到账日 vs 按分配日；
3. **折年化基准**：360 天 vs 365 天；
4. **累计期次口径**：是否剔除年度受托报告的累计列（重复计入会导致回收与利息算两遍）。

因此：**本仓库的指标是对披露信息的重构，不等同于任何机构的官方口径**。
用于对外披露或内部考核前，请用你所在机构的台账复核。

## 四、使用者的责任

- 若你所在机构对工作产物有保密或审批要求，**公开引用前请先走内部流程**；
- 请勿把本仓库产物与其原始披露文件混同——产物是加工件，不是原件；
- 项目方名称、证券简称等出现在分析中，仅为标识标的，不构成对其信用状况的评价。

## 五、不构成投资建议

本仓库全部内容为技术方法示范，不构成任何证券的买卖建议、估值意见或投资顾问服务。
不良资产证券化的次级档回收高度不确定，历史回收率不代表未来表现。
