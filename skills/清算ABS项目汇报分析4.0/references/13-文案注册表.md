# 13 · 文案注册表（渲染后文本 = 唯一权威）

> **为什么必须有这个**：其他 agent 复刻失败，最常见的原因不是代码跑不通，而是**文字不一样**——
> 标题少一个字、口径注释变了措辞、KPI 名改了个说法，用户一眼就能看出来"这不是那份报告"。

## 一、权威数据在哪

| 载体 | 内容 | 用途 |
|---|---|---|
| `assets/golden/report_spec.json` → `views[].text` | **每个视图渲染后的完整可见文本**（上限 60,000 字符/视图） | 逐行 diff 的唯一权威 |
| `assets/golden/report_spec.json` → `views[].sections` | 每视图 h2/h3 标题与顺序 | 结构级文案 |
| `assets/golden/report_spec.json` → `meta.navText` | 侧栏菜单文案与顺序 | 导航级文案 |
| `assets/specs/逐单报告_写作规范_v1.md` | 写作规范（**为什么这么写**） | 改文案时的依据 |
| `assets/specs/报告改写_规格_v2.md` | 改写规格 | 同上 |

**注意**：必须是**渲染后**文本。客户端改写模块（`70_wording.py`）会在运行时替换大量文案，
源 HTML 里仍是原文——比对源文件会得到假结果。

## 二、关键文案清单（改这些必须同步基线）

### 2.1 页面级

| 位置 | 文案 |
|---|---|
| 页面标题 | `清算 28 单 · 单项目穿透分析报告` |
| 侧栏标题 | `清算 28 单 · 穿透分析` |
| 侧栏副标题 | `单项目八节 · 国有/股份 → 银行 分组导航` |
| 侧栏入口 | `◆ 全部项目（28）` / `► 横向对照` / `► 明细与底稿` |

### 2.2 总览看板

- 首句：**`按品种分组、组内按发起机构归集`** 的 28 单 KPI 速览（品种色仅作分类标识；卡片 chip 标注发起机构与品种）
- 口径提示条：`达成率＝资产池回收 ÷ 中债预测回收；与证券端本息兑付率不是一个口径，两者不矛盾。达成率低于 100% 仅表示资产池回收少于中债预测，不代表证券端本息未兑付。`
- 语义色说明：`品种色为分类标识，不代表风险等级。`
- 指标口径副行：`合计` / `规模加权 · n=22` / `**算术平均** · n=22` / `中位数 · n=22` / `笔均 · n=23`
- ⚠ 用「**算术平均**」，**禁止**「简单平均」

### 2.3 单项目档案

- 5 类分组顺序（**不得改序**）：
  1. `资产池情况`
  2. `集中度与账龄`
  3. `预期回收与发行结构`
  4. `实际回收与处置`
  5. `实际收益与期限`
- 终局性徽章（二选一）：
  - `信托计划已终止 · 清算完成 YYYY-MM-DD`
  - `信托计划存续中`
  - ⚠ **禁止** `已终局`
- 证券端分项事实：`证券端：优先档本金已兑付 100.00% ｜ 次级档本金已兑付 99.99%`
- 清仓回购（仅发生时）：`已经清仓回购（回购价格 X 元）`
- 字段字典折叠块：`字段字典 · ② 集中度与账龄（7 个字段的可得率与缺失原因）`
- 缺失一律 `未披露` 或 `—`（**禁止空、禁止 0**）

### 2.4 横向对照（5 板块标题，逐字）

```
01 四象限：实际回收率 × 处置费率，气泡 = 资产本金规模
02 中债预测回收率 vs 实际回收率
03 定价假设 vs 实际兑现 + 次级档超额收益
04 回收款去向：全周期瀑布 + 逐期堆叠 + 费用帕累托
05 各家实际各单 IRR（XIRR）点评
```

- 03 固定图注（逐字）：
  `哑铃/叠加图比较优先档票面利率与优先档 XIRR，票面为定价假设、XIRR 为现金流口径，二者不可直接等同；次级档仅展示披露 XIRR，不进行固定资金成本倒算。`
- 04 瀑布图注（逐字）：
  `中间支出项按金额降序排列，非合同支付顺序；期初、回收流入、期末位置不变，累计扣减逻辑不变。`
- ⚠ **全站禁止**：`折价率` / `预测 XIRR` / `倒算率` / `可倒算` / `约定资金成本率` / `固定资金成本率` / `发行利差`

### 2.5 明细与底稿

- 页头：`明细与底稿`
- 说明：`以下为细粒度数据与可深挖内容，默认收起；展开不影响主结论阅读。`
- 5 个折叠块说明（≤20 字）：
  `三类资产池横向对比` / `9 家机构强弱与异常点` / `4 条可复用判读` / `全字段逐单读数` / `S1–S10 数据欠账`

### 2.6 数据质量与披露（⑧）

- 折叠头：`披露 N 项`（无缺口：`披露 0 项 ｜ 无缺口`）
- 展开首行：`披露概览：共 N 项 ｜ 已回源补全 a 项 ｜ 源未披露 b 项 ｜ 源文件缺失 c 项`（**N=a+b+c**）
- 三段式：`① 数据完整度` / `② 口径注解` / `③ 来源依据`
- ⚠ **禁止**内部编码 `A_回源已补` / `B_报告确无` / `C_源文件缺失`

## 三、禁止出现的词（门禁会查）

| 类别 | 词 |
|---|---|
| 错误口径 | 折价率 |
| 不存在的字段 | 预测 XIRR、发行利差、约定资金成本率、固定资金成本率 |
| 已废判据 | 已终局 |
| 内部编码 | payload.、pool.、liq_info、ref_rate、A_回源已补、B_报告确无、C_源文件缺失、残迹待核 |
| 本地路径 | `E:\`、`E:/` |
| 旧口径名 | 简单平均（→算术平均）、处置费用占比（→处置费率）、账户配平（已删） |
