## 四、农行项目命名与“毛病”的原因

农行的产品线按资产类型拆成不同系列，名字不同不是错：

| 系列 | 资产类型 | 说明 |
|---|---|---|
| 农盈利信 | 信用卡不良 | 2021 年各期 |
| 远新 / 远诚 | 信用卡不良 | 2022–2023 各期 |
| 惠众 / 惠泽 | 个人经营贷款（零售信贷） | 2021–2023 各期 |
| 众兴 / 众合 | 住房抵押 / 个人消费 | 2023 以后，本次未纳入清算样本 |

同一系列不同期次的说明书、受托报告、清算报告由不同受托/审计机构出具（建信信托/交银信托、德勤/毕马威/立信等），表格列序、章节名、金额单位不同，所以解析要逐期适配。

**已修正的一处口径错误**：此前农行 6 单在数据里被统一标成“信用卡不良”，现按说明书正文重新识别为信用卡/个人经营，工作台已按新口径统计。
