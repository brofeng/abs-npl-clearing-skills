## 四、省时策略（说明书 681 页怎么不耽误时间）

**不要通读，用「页锚点 + 关键词定位」**。本单实测：所有需要的数都在下面这些位置。

| 需求 | 位置 | 检索关键词 |
|---|---|---|
| 证券要素（规模/票面/到期/支付日/期限） | p2–p4 | `发行规模`、`票面利率`、`支付日`、`加权平均期限` |
| 资产池概况表 | p5–p8 附近 | `未偿本息费余额`、`加权平均逾期期限` |

| 交易结构 / 分配顺序 | 第四章 | `现金流分配`、`(a)`、`超额奖励` |
| 处置费用条款 | p87 附近 | `处置费用`、`17%` |
| 清仓回购条款 | 信托合同章节 | `清仓回购`、`回购价格` |

**推荐做法**（技能已内置分页文本，可直接按页取）：

```python
# 02_提取数据/文本/SM.txt 是按「===== P<页码> =====」切好的
# 只读需要的页区间，不读全文
```

```bash
# 定位关键词所在页
python -c "
import re,io
t=io.open('SM.txt',encoding='utf-8').read()
page=0
for line in t.split('\n'):
    m=re.match(r'^===== P(\d+) =====',line)
    if m: page=int(m.group(1))
    if '处置费用' in line: print('p%d'%page, line.strip()[:80])
"
```

## 五、三条纪律

1. **一个指标只认一个源**，且必须在报告里可追溯（本技能在各节注释里写明「源：说明书 pXX」或「中债口径」）。
2. **交叉校验 ≠ 混用**：用联合资信的表校说明书没问题；发现不一致时**不取平均、不取"看起来对"的那个**，
   而是回原始披露文件判定，判定不了就按主口径取并在注里写明另一口径的值。
3. **评级报告不作为存续期数据的源**：评级报告是发行时点（或跟踪时点）的静态分析，
   逐期回收、分配、清算数只能来自受托机构报告与清算报告。
