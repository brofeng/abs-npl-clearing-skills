# 02 · 口径纪律

> 一份穿透报告的可信度 = **口径一致性** × **可追溯性**。
> 本文件是硬约束，任何模块都不得违反。

## 一、唯一口径表（全报告只认这一套）

| 指标 | 定义 | 禁止 |
|---|---|---|
| **证券化率** | 发行规模 ÷ 入池本息费 | ❌ 禁止用「折价率」三个字 |
| **处置费率** | 处置费用 ÷ **累计回收** | ❌ 禁止 ÷ 入池本息费 |
| **回收率** | 累计回收 ÷ 入池本息费 | |
| **达成率** | 实际回收率 ÷ 中债预测回收率 | ❌ 不得称「达成率 = 证券兑付率」 |
| **XIRR** | 货币加权、现金流口径 | ❌ 不得与票面利率直接等同 |
| **资产本金规模** | `poolPrincipal` | ❌ 不得用发行规模冒充 |
| **信托终局** | 以**信托计划是否终止**为准（有 `liquidation_date`） | ❌ 不得以「本金全额兑付」判终局 |

### 处置费的三个层次（容易混）
- `disposeFee`：处置费用**金额**
- `disposeFeeRate`：处置费用 ÷ 累计回收 —— **处置费率**（唯一口径）
- 「处置费用占比」= 同一公式 → **与处置费率同义，只保留一个**

## 二、终局性判定（曾经判错）

**错误做法**：本金两档都兑付 100% → 写「已终局」。
**正确做法**：

```
有 liquidation_date → 「信托计划已终止 · 清算完成 YYYY-MM-DD」
无 liquidation_date → 「信托计划存续中」
本金兑付率 → 降为独立分项事实：「证券端：优先档本金已兑付 100.00% ｜ 次级档已兑付 99.99%」
若发生过清仓回购 → 追加「已经清仓回购（回购价格 X 元）」
```

判断依据：`payload.h5_clauses.trigger_kind`（B 主动发《清仓回购通知书》 / A 本金兑付完毕后程序性终止）、`buyback_price`。

## 三、单位纪律

```
金额：≥1 亿 → 「x.xx 亿」；≥1 万 → 「x.xx 万」；<1 万 → 「元」
同一图内：中心值 / 图例 / 轴 / tooltip 必须同源同单位
同一面板内：不得亿/万混排（① 资产池 3 格全亿；② 集中度全万，因为都是单笔户均）
百分比：1–2 位小数，全报告统一
```

**曾出的硬错**：圆环图数值是「亿」量级却标「万」——**差 10000 倍，且图内单位词完全自洽**（全标「万」），所以「同图单位一致」的断言抓不到。必须做**跨图/跨指标量级校验**：分布图合计必须在 [1000 万, 1000 亿] 区间，或与同页 KPI 同名指标相对误差 ≤2 倍。

## 四、XIRR 相关（最容易被误读）

1. **XIRR ≠ 票面利率**。优先档 XIRR 与票面偏差通常只有 **−1~+4bp**（实测），但概念不同：票面是定价假设，XIRR 是现金流口径
2. **不可倒算次级档资金成本率**：全库无「约定资金成本率」字段，`xirr.sub.ref_rate` 存的是**优先档票面**（`ref_rate_src="优先档票面"`）不是次级约定率
3. 若一定要倒算，公式必须是 **`r = Σ固资 ÷ Σ(期初剩余本金 × 天数/365)`** —— 用**期末**口径会把率算高一倍
   - 实例：中誉至诚2023第四期 期初口径 **12.00%**（与说明书 p187 的 12% 一致）、期末口径 **21.47%**（错）
   - **本技能建议：不做倒算**，只展示披露值
4. 次级档只展示**披露 XIRR**（8.41%–27.91%，中位 11.48%，n=28），不做任何推导

## 五、数据质量披露（三段式，不是排雷叙事）

每单的「数据质量与披露」写成三段，**总长 ≤ 原 40%**：

```
① 数据完整度：本单 8 类核心字段齐全，无缺项 / 缺 3 项：X/Y/Z
② 口径注解：预计回收采用中债口径；另有中诚信/世联口径见附录
③ 来源依据：发行说明书（202406）；受托机构报告第 1–5 期
```

**禁止出现**：`payload.xxx`、`pool.bsf`、`liq_info.setup_date` 这类内部字段路径；`A_回源已补/B_报告确无/C_源文件缺失` 这类内部编码；本地 `E:\` 路径；历史排雷过程。

若确需展示披露统计，用**中性表述**：
> 「披露概览：共 N 项 ｜ 已回源补全 a 项 ｜ 源未披露 b 项 ｜ 源文件缺失 c 项」（N=a+b+c 恒等式）

## 六、自检清单（每轮交付前跑）

- [ ] 全站「折价率」= 0
- [ ] 处置费率分母唯一（`处置费率 = 处置费用 ÷ 累计回收`，断言其公式串不含「入池」）
- [ ] 「已终局」= 0，且「信托计划已终止/存续中」覆盖全部单
- [ ] 无「预测 XIRR」「发行利差」「约定资金成本率」等不存在字段
- [ ] 无内部字段路径、无本地路径、无内部工作编码
- [ ] 同面板单位不混排；分布图合计与 KPI 量级一致
- [ ] 缺失一律「—」或「未披露」，不显示 0
- [ ] n 全部动态计算
