## 3. HTML 现金流板（第 14 个）

- 参考「资金平衡 / 分配瀑布 / 多账户勾稽」的账本横条；
- 4 个指标卡：可分配现金 / 优先档 / 次级档 / 费用；
- 图例：优先/次级/费用/其他；
- 银行分组 + 100% 横条 + 右侧金额/单数；
- 标签只在大段显示；小段用 title；
- 颜色同主题；不要高饱和渐变；
- 点行进入银行+品种；
- 卡片与上方网格 14px，通栏。

## 4. 双列

6 组 `.v3-pair`：
矩阵+计分卡、资产池+策略、票面+优先×次级、预测+分布、资产质量×2、发行+年度表。

- 桌面两列等宽；≤900px 单列；
- 两张卡尽量等高；图表高度已配好（390/360/340 等）；
- 卡片间距 14px，内部 gap 14px；
- 不要留下大块空白：s4 偏差表外置、s5 注释补齐、s7 图表配对。

## 5. 字体与数字

- 中文：微软雅黑 UI / Microsoft YaHei；
- 数字：tabular-nums；
- 图内 9.5–11.5px；卡片标题 12–13px；
- 百分比保留 1 位小数；金额按亿保留 1 位；倍数 2 位；
- 轴标题、图例、单位不能裁；图例窄屏滚动。

## 6. 夜盘 / 打印

- 夜盘：深色壳层，图表暖纸；银行色不反转；表格可读；
- 打印：两栏、隐藏壳层、卡片避免断页、报告头带切片；
- HTML 现金流板打印要完整，不截断。

## 7. 反模式

- 用高饱和渐变做现金流板 → 与主题冲突；
- 所有卡片通栏 → 大片留白；
- 只给一张卡加 margin-top → 间距不统一；
- 气泡图没有中位线 → 四象限读不出来；
- 图表高度改小但轴标签不调 → 裁切；
- 在 1366/1600 之外用固定 window-size 验收 → 响应式断点漂移。
