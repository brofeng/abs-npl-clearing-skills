# 04 · 图表规范

## 一、选型决策表（先按数据形态选，不要凭感觉）

| 数据形态 | 图型 | 禁止 |
|---|---|---|
| **有序分箱**（余额/逾期/年龄/收入/授信/预计回收率） | **垂直柱状**；看头部集中度用**帕累托**（柱 + 累计占比折线，右轴 0–100%） | ❌ 圆环 |
| **少类别占比 ≤5** | **100% 堆叠水平条** / 单行占比条 | |
| **单一类别**（如担保方式 100% 信用） | 一条横向占比条 + 文字「信用类 100%」 | ❌ 圆环 |
| **多类别无序长尾**（职业 37、地区 342） | **排序水平条形 Top8/Top10 + 「其他（n=x）」**，按值降序 | ❌ 高密度圆环、❌ treemap |
| **目标 vs 实际，差距小（<1pp）** | **排序条形 + 另一值叠点**（条=一个值，点=另一个值） | ❌ 哑铃（差距 1–4bp 会画成平线） |
| **目标 vs 实际，差距大** | 哑铃 / 斜率图 / 45° 散点 | |
| **资金流向** | **瀑布**（两端固定、中间按金额降序）+ 逐期 100% 堆叠 + **费用类帕累托** | ❌ 圆环表达流向 |

### 硬性规则
1. **不要为了「统一」把所有图改成同一种图型**（曾把 10 张分布图全改成横条，被用户纠正）
2. **图型多样性 ≥4 种**；**圆环 0–2 张**（仅当类别 ≤4、标签 ≤6 字、卡宽 ≥360px）
3. **禁止彩虹色**：单系列同色系 3–5 档；语义色只用于风险/异常（五级分类、担保方式）；合并项**中性灰**
4. **主色 ≤6**

## 三、横向对照五板块

| 板块 | 图型 | 关键点 |
|---|---|---|
| **01 四象限** | 气泡散点 | X=**处置费率**、Y=实际回收率、气泡=**资产本金规模**（`poolPrincipal`，**不是**发行规模）、颜色=品种、中位十字线、四角象限名、Top3 规模点；脚注写**内生/同向、不解读为因果**、n=27 |
| **02 预测 vs 实际** | 45° 对角线散点 + 比值直方图 | **图内不标逐项目差异**（只留点/红环强调）；差异进 tooltip；`diff_pp = 实际 − 预测`；不称「达成率」 |
| **03 定价假设 vs 兑现** | **票面排序条 + XIRR 叠点** + 优先档偏差分布 + 次级档 XIRR 披露分布 + 超额收益 Top10/Bottom5 | ❌ **不做任何倒算**；票面 2.00%–3.15%（115bp）而偏差仅 −1~+4bp → 哑铃会退化 |
| **04 回收款去向** | 瀑布 + 逐期 100% 堆叠 + **费用类帕累托** | 瀑布中间项**按金额降序**、图注写「非合同支付顺序」；帕累托**只对费用科目**（证券本金/利息会把图压平） |
| **05 定价思考** | 汇总表 + 点评（无图） | 按银行/品种汇总 n、优先/次级 XIRR 中位与区间、异常单；只读披露值 |

## 四、版式与尺寸

| 项 | 规范 |
|---|---|
| 栅格 | 桌面 ≥1180px：12 列（主图 8 / 辅助 4；矩阵 3 列等宽等高）；平板 6 列；手机 1 列 |
| 卡片结构 | 标题区 1 行 / 绘图区 `flex:1` / 图例区 **40–48px** / 脚注 1–2 行 |
| 卡片高度 | 由栅格锁定，**不允许内容撑高**；行内等高（高差 ≤4px）；行高上限 300px |
| 字体 | 标题 12px / 数据与图例 10–11.5px / 图注 9.5–10.5px；**同图 ≤3 种字号**；不要把字号缩到 9px 塞内容 |
| 图例 | 最多 2 行；按**实测文字宽度**排布，两两不重叠；与单位徽章间距 ≥16px |

## 五、SVG 规范

```html
<svg viewBox="0 0 W H" preserveAspectRatio="xMidYMid meet" role="img" aria-label="...">
```
```css
svg { width: 100%; height: 100%; display: block; }
```
- **禁止写死 `width="680" height="240"`**
- `viewBox` 宽按**卡片实测内容宽**计算；高度 = 内容实高（不留白）
- 宽度变化 >10px 自动重绘（`data-v2c-w` 记录）

## 六、标签与 tooltip

- **数值标签只标** Top / Bottom / 异常 / 四角 / 端点；其余走 tooltip
- **任何被截断的标签必须有完整 `title` / tooltip**
- **口径/图型说明行放在 SVG 外部的 HTML 兄弟节点**（否则旋转轴标签会与脚注重叠；实测最小间距要 ≥6px）
- tooltip 用 `position:fixed`，避免被 `overflow:hidden` 裁剪

## 七、两个必须加的量级校验

1. **圆环/分布图中心合计**：必须有数字+单位；金额必须在 [1000 万, 1000 亿] 合理区间，或与同页 KPI 同名指标相对误差 ≤2 倍
2. **图例各项之和 / 中心合计**：相对误差 ≤1%（防「各部分加起来不等于合计」）

## 八、异常与备注

- 数据异常**按源数据如实呈现**，图下加通栏备注，**不擅改数**
- 例：信用卡不良「担保方式」出现「抵押 10.07%」→ 图下通栏注：
  > 注：本单底层为信用卡类资产，源说明书「担保方式」中含抵押/保证合计 10.12%（余额 2.26 亿元），与信用卡通常无抵押的情况不符，按源数据如实呈现，**待回源核实**。
- 备注放**网格下方通栏**，不占卡片高度

## 九、折线

- **平滑曲线**用单调三次插值（Fritsch–Carlson）→ 贝塞尔，**不过冲**
- 线宽统一细线 **1.6px**（面积图描边 1.4px）；同图所有线段粗细一致
- ❌ 禁止无数据含义的折线
