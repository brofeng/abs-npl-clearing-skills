# 上架 WorkBuddy 技能市场 · 实操手册

> 目标：把两个技能挂到 WorkBuddy 技能市场，所有人可搜到、一键安装。
> 平台：**open.workbuddy.cn**（开放平台网页版）。客户端只负责「做技能 / 装技能」，上架在网页端。

---

## 0. 先看结论：哪些必须你本人做

| 环节 | 谁做 | 原因 |
|---|---|---|
| 注册、个人实名认证（含人脸识别） | **你本人** | 涉及身份证与人脸，无法代办 |
| 上传 zip、填市场信息、提交审核、点发布 | **你本人** | 登录态在你账号里 |
| 打包 zip、写 SKILL.md、生成头像、写文案 | 已完成 | 见 `market/` 与本文表格 |

---

## 1. 账号与认证（一次性，约 10 分钟）

1. 打开 **open.workbuddy.cn** → 点「立即入驻」；
2. 手机验证码登录（或微信登录）；
3. 选 **个人认证**（个人主体即可上架技能与专家），按提示完成身份证 + 人脸识别；
4. 认证通过后进「设置 → 开发者信息」，补齐：**昵称**（全平台唯一）、**简介**、**头像**、
   至少一项联系方式。**不补齐会卡在发布**。

> 昵称别用别家平台名（如「小红书」「公众号」），会被驳回。

## 3. 上传与审核（每个技能约 5 分钟）

1. 左侧「**发布管理 → 技能**」→ 右上「**创建**」；
2. 拖入 zip。平台自动解包解析，读出 `name / display_name / version / description`；
3. 选分类、上传 512×512 头像 → 「继续」；
4. 确认页核对：展示名、版本、价格（免费）→ **提交审核**；
5. 审核中 → 通过后状态变「**待发布**」；
6. **待发布 ≠ 已发布**，还必须点一次「**发布**」，状态变「已发布 · 公开」才算上架。

审核时效官方写 7 个工作日，实际常见当天至次日。

## 4. 避坑清单（平台实测的硬规则）

| 坑 | 现象 | 解法 |
|---|---|---|
| 包超 3MB | 上传直接拒绝 | 本仓库已裁到 1.93 MB / 0.49 MB，别手动加回 V9 和截图 |
| frontmatter 缺字段 | 报「缺少 Skill 中文展示名 / 英文描述…」 | 本仓库已补齐 6 个必需字段 |
| 版本号两段 | 报「格式不合法，请用 1.0.0」 | 已改 4.2.0 / 1.0.0 |
| SKILL.md 埋太深 | 报「未找到 SKILL.md」 | 必须在 zip 第一层目录里（本包已符合） |
| 提审次数限制 | 每天技能 5 次、每月合计 20 次 | 一次成型再传，别反复空传 |
| 更新版本掉头像 | 更新后头像变空 | 每次「更新版本」都重传一次头像 |
| 名字含他家平台名 | 驳回 | 已避开 |
| 价格不能改 | 发布后免费/收费不可切换 | 先免费，想收费等条件成熟再单独提新包 |

## 5. 想收费时的路径（可选）

1. 先有 **至少 1 个过审资产**，「收入变现」入口才会开；
2. 完成开发者认证 + 无违规记录 + 本人实名 + 微信签约；
3. 观察期内**只能发布 1 个付费资产**，首单成交后才解锁更多；
4. 建议顺序：技能一免费冲安装量 → 技能二（或后续增强包）占付费名额、低价试水。

> 本项目的建议：**先都免费**。ABS 分析属专业垂直场景，受众窄但决策重，
> 免费换安装量与 Issue 反馈，对后续优化更划算。

---

## 6. 推广

「推广管理 → 新增推广」→ 选技能 → 生成分享链接 / 小程序码 → 填渠道标签（如「知乎」「公众号」）。
「推广效果」里能看各渠道曝光与安装。

---

## 7. 更新已上架技能

1. 改仓库里的 `skills/<name>/`；
2. `python -X utf8 tools/build_market_package.py` 重新出包；
3. 平台技能卡片 → 「更新版本」→ 传新 zip → 升版本号（4.2.0 → 4.2.1）→ 提审；
4. 过审后**再点发布**，并**重传头像**。
