## 7. 失败处理

| 失败 | 先查 | 不要做 |
|---|---|---|
| G0 DIFF | 解压/改源 | 不要用 `--write` 掩盖 |
| G1 略差 | 换行/编码/路径 | 不要手改 dist |
| G1 大差 | base/rows/source 错 | 不要重写注入器 |
| 行数少 | 项目目录/名称 | 不要补空行 |
| 公式失败 | exp/achieve 四舍五入/单位 | 不要放宽到 0.1 |
| 现金流 0 | REPORTS/data-label | 不要跨项目借 |
| charts 12 | JS 错/现金流板未渲染 | 不交付 |
| G3 银行页失败 | 报告键/项目键 | 不要改测试绕过 |
